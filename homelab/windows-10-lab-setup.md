# Windows 10 VM Lab

## Objective

Set up a Windows 10 virtual machine using VMware Workstation for cybersecurity labs.

## Environment

* VMware Workstation
* Windows 10 ISO

## Steps

1. Installed VMware Workstation.
2. Created a new virtual machine.
3. Selected the Windows 10 ISO image.
4. Manually installed Windows 10.
5. Completed the Windows setup and logged into the desktop.
